## 🌟 Featured Projects

### 🎥 VideoTube — Full-Stack Backend for a Video Sharing Platform
Built a REST API backend for a YouTube-style platform: secure user registration with multi-file upload (avatar + cover image) via Multer & Cloudinary, MongoDB schemas designed with Mongoose, standardized error handling with custom utilities, and every endpoint tested end-to-end in Postman + MongoDB Atlas.

**Tech:** Node.js • Express.js • MongoDB • Mongoose • JWT • Multer • Cloudinary
**Repo:** https://github.com/ravimali-dev/JavaScript-Backend

### 📝 Blogify — Full-Stack Blogging Platform
A blogging platform where users can sign up, log in, and create/edit/delete their own posts. Uses Appwrite as backend-as-a-service (auth, database, storage) and Redux Toolkit for global state management across the app.

**Tech:** React.js • Redux Toolkit • Appwrite
**Live:** https://blogify-three-rho.vercel.app/

### 📋 Queue Management System — Real-Time Queue Tracking App
A queue tracking application built from scratch in React (no boilerplate), with independently designed component architecture and state logic for real-time queue position updates.

**Tech:** React.js
**Live:** https://queue-management-system-black.vercel.app
**Repo:** https://github.com/ravimali-dev/Queue-Management-System
